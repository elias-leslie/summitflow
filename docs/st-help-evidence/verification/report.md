# Independent ST help verification

**Pass for the retained local help evidence, with bounded accuracy and cost claims.** The [before](before.json) and [after](after.json) inventories invoked the installed `backend/.venv/bin/st` and each had stable source hashes during capture. The retained graph has 243 native Click routes (including root and hidden aliases); the final captures contain 242 native outputs, 272 metadata pages in 23 extension namespaces, and 24 safe manual help invocations: 538/538 returned nonempty text with exit 0. All 46 manual dispatch routes were inventoried structurally; `st check` modes that would execute a gate when given `--help` were not invoked. The [comparison](comparison.json) preserves matching native signatures, extension bindings and metadata routes for this retained scope. Every retained metadata page resolves to its registered parent and equals its captured manifest text after newline normalization. An independent canonical focused gate passed 193 tests: `st check pytest -- backend/tests/cli/test_extensions.py backend/tests/cli/test_help_reference.py backend/tests/cli/test_operator_tools_cli.py backend/tests/cli/test_st_sdk.py backend/tests/cli/test_tasks_autocode.py`.

The [owner parity check](owner-option-parity.json) retains comparisons of frozen read-only owner captures with 272 manifest pages: 272/272 route keys, option names, and exact `[default: ...]` values match. Those captures preceded final prose-only owner edits; I also checked corrected Mandates, Automations, UI, Selection, and Health help in final source/rendered output. [Held-out raw probes](help-route-probes-after.json) show that a `models --id list` value no longer selects `list` help, while valid `--id foo list`, `--id=foo list`, and `--free list` still do. Malformed prefixes now show ancestor help rather than an unrelated leaf. ST's passive help returns exit 0 on some invalid owner argv where the owner parser would exit 2; it is not a full owner argument parser.

Help output is **more complete, not universally shorter**. The artificial total for retained pages rose from 58,596 to 59,612 `ceil(returned UTF-8 bytes/4)` estimates; root help rose 1,466→1,560, `search --help` 425→551, and `automations runs --help` 19→75 as pagination/defaults were restored. `db query --help` fell 191→38 by replacing the repeated root matrix with exact leaf syntax. Root's generic `Agent Hub-owned` summaries fell from 11 to 1. These are output estimates and navigation evidence, not measured model tokens, agent task success, or task latency. The installed local CLI imports this checkout; final hosted-release parity needs the parent's managed deployment receipt.
