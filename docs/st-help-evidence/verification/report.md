# Independent ST help verification

**Pass for the installed local help surface, with bounded accuracy and cost claims.** The [before](before.json) and [after](after.json) inventories invoked the installed `backend/.venv/bin/st` and each had stable source hashes during capture. Final coverage is 244 native Click routes (including root and hidden aliases), 413 metadata pages in 24 extension namespaces, and 24 safe manual help invocations: 681/681 returned nonempty text with exit 0. All 46 manual dispatch routes were inventoried structurally; `st check` modes that would execute a gate when given `--help` were not invoked. The [comparison](comparison.json) found no lost native route, option spelling, default, type, requiredness, extension binding, or existing metadata route. Seven missing Neri leaves were added. Every metadata page resolves to its registered parent and equals its manifest text after newline normalization. An independent canonical focused gate passed 193 tests: `st check pytest -- backend/tests/cli/test_extensions.py backend/tests/cli/test_help_reference.py backend/tests/cli/test_operator_tools_cli.py backend/tests/cli/test_st_sdk.py backend/tests/cli/test_tasks_autocode.py`.

The [owner parity check](owner-option-parity.json) compared frozen read-only owner captures with all 413 manifest pages: 413/413 route keys, option names, and exact `[default: ...]` values match. Those captures preceded final prose-only owner edits; I also checked corrected Mandates, Automations, UI, Selection, and Health help in final source/rendered output. [Held-out raw probes](help-route-probes-after.json) show that a `models --id list` value no longer selects `list` help, while valid `--id foo list`, `--id=foo list`, and `--free list` still do. Malformed prefixes now show ancestor help rather than an unrelated leaf. ST's passive help returns exit 0 on some invalid owner argv where the owner parser would exit 2; it is not a full owner argument parser.

Help output is **more complete, not universally shorter**. The artificial all-pages total rose from 67,269 to 68,730 `ceil(returned UTF-8 bytes/4)` estimates; root help rose 1,466→1,560, `search --help` 425→551, and `automations runs --help` 19→75 as pagination/defaults were restored. `db query --help` fell 191→38 by replacing the repeated root matrix with exact leaf syntax. The previously missing `neri research hypotheses --help` now resolves to a 38-estimate leaf rather than the parent page. Root's generic `Agent Hub-owned` summaries fell from 11 to 1. These are output estimates and navigation evidence, not measured model tokens, agent task success, or task latency. The installed local CLI imports this checkout; final hosted-release parity needs the parent's managed deployment receipt.
